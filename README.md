# RPG弹药扩展 (RpgAmmoExpansion)

## 简介
这是一个为《卓越前线》(Superb Warfare, SBW)设计的小型修补模组，主要对RPG-7火箭筒进行了功能扩展，让玩家能够享受更丰富的游戏体验。

## 功能特性
- **多发弹药容量**：RPG不再限制为单发装弹，可通过配置文件调整弹药容量
- **自动射击模式**：将RPG变成火箭机关枪，支持全自动连发
- **可调整射速**：通过配置文件调整RPG的射击速度，打造你的专属速射火箭筒
- **无缝装弹**：修复了原版RPG的一些装弹问题，使武器操作更加流畅

## 配置选项
第一次运行后，模组会在config文件夹中生成配置文件，你可以根据需要调整以下设置：

- `rpgMagazineSize`：RPG弹药容量（默认：10）
- `disableEmptyAfterShot`：射击后不自动标记为空（默认：开启）
- `rpgVelocityMultiplier`：RPG射击速度倍率（默认：3.0，数值越大发射越快）
- `enableAutoFireRPG`：启用RPG自动发射模式（默认：开启）

## 兼容性
- 需要Minecraft 1.20.1
- 需要Forge 47.3.0+
- 需要《卓越前线》(Superb Warfare) 0.7.6+

## 使用提示
- 切换RPG的射击模式可以按下Mod键（默认为N）
- 在自动模式下，只需按住鼠标左键即可连续发射火箭弹
- 配置较高的弹药容量可能会使游戏平衡性降低，请根据个人喜好调整
